How it's stored

The section and field definitions above are the whole list below. In a database they'd be two tables, one row per section and one row per field. 

{{ sections() | json }}

Each procedure keeps the values for every field in one extraFields bag, keyed by the field's Key. Adding a field adds a key there, not a new column. Blank values aren't stored.
