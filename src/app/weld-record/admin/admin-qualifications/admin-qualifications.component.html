Qualifications

A step that matches a condition requires its quals before sign-off. Controlled Material, SS, SFFF, N Ind. and Titanium are checked as soon as a step with a Qualification Check opens. Inspection Type is checked once the step's Type is picked.

Controlled Material is Yes when MCL 1 or MCL 2 requires traceability in Admin > Material Traceability. Titanium is Yes when either Material Type is marked Titanium in Admin > Material Classification.

The toggle on each qual shows whether the {{ userName }} holds it. Toggles save right away. Condition changes save with the Save button.
